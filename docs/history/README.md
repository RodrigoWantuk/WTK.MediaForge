# Historical Documents

Files in this directory preserve earlier CP, phase, Studio exploration, and
readiness evidence. They are intentionally non-normative and may describe APIs,
statuses, or gates that no longer exist.

Current work must use `docs/ROADMAP_CURRENT.md`, `docs/AI_CONTEXT.md`,
`ARCHITECTURE.md`, `docs/PUBLIC_API.md`, `docs/GPU_MEDIA_SUPPORT_MATRIX.md`, and
`docs/REVIEW_CHECKLIST.md`. The scripts under `readiness-scripts` are archived
text and are not current executable gates.
